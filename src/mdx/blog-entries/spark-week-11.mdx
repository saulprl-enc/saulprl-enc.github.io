# Spark Week 11

For my 11th week in the Spark Program, I focused on my Udemy course for the AWS Developer Associate certification, as well as preparing for my very first **Lightning Talk**; regarding meetings, we also had a *Spark Communication Sessions* that introduced us to a new topic. ## Spark Communication Sessions
<br />

For this week's *Spark Communication Sessions*, we talked about the previous week's assignment where we got to make a 3-minute presentation about a topic related to food. Unfortunately, I still hadn't gotten feedback by then, but I feel confident that I did pretty good. The new topic we covered was **active listening**, and we not only defined the concept itself, but also the different parts that would allow us to improve at this skill. For instance, we heard about having to be attentive, asking follow-up questions, and giving feedback to the person we're listening to. Also, some individual skills we can work on while simultaneously improving our active listening overall: analytical and relational (and two more that I can't remember right now) listening. At the end of the session, we also had a few minutes to **practice** and just talk to each other about any topic we wanted, which felt weird at first but eventually managed to sit on a topic for a while.

## AWS Developer Associate
<br />

For the certification, I've focused on the Udemy course to use it as an AWS refresher (since I've worked with AWS before), and so far I've been hooked on learning the theory behind every service AWS offers. For instance, I've used IAM and toyed with the different policies for services like S3, EC2, volumes, and RDS (even though I haven't seen this one on the course). Regarding EC2 instances, I've done multiple exercises in the past, but never really understood how creating images (AMIs) worked, and this course explained it very well by covering volumes and snapshots beforehand. Finally, I worked on some labs for learning how Load Balancers work, but in the past I had only worked with the Application Load Balancer and never really understood what the others (NLBs and GWLBs) did, or why the ALB worked in the first place, so this course explained it very well and it inspired me to choose this topic for the Lightning Talk.
<br />

## Lightning Talk
<br />

In the middle of the week, I had planned on making a presentation about passkeys since it's a topic I've never researched before but have read about it when they were first released. Later, I decided to focus on learning how Load Balancers worked behind the scenes, and discovered that they're essentially algorithm implementations centered around distributing workload as efficiently as possible. I learned about the existence of static and dynamic algorithms and took a little extra time learning how some of them work.
<br />

Regarding the talk itself, I felt really confident going into it because I had a good grasp on the topic and like giving talks in general. I tried taking a couple of additional things into account (like eye contact and vocal tone) since they're areas I've always known I lack in, and overall did pretty good. There's one more thing I need to work on, though, which is time management. Ironically, I was actually keeping track of time during the talk, but I might've overexplained a few things and didn't want to end the presentation abruptly, so that's something to keep in mind for next week.
